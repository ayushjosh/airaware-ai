# AirAware AI

### An AI-Powered Air Quality Decision Assistant

AirAware AI is a conceptual/working prototype aligned with **SDG 11 — Sustainable Cities and Communities**.

The project explores how AI-assisted explanation and knowledge retrieval can make air-quality information easier to understand and use in everyday outdoor-activity planning.

## Problem

Air-quality information such as AQI, PM2.5 and PM10 can be difficult for everyday users to interpret quickly. Users may see numerical values without understanding their meaning in the context of an activity such as jogging or walking.

AirAware AI aims to translate supplied air-quality information into understandable context while keeping the system within an informational decision-support role.

## How It Works

Users provide:

- AQI
- PM2.5
- PM10
- Activity type
- Activity duration

The prototype processes the supplied information and provides:

- AQI category
- Plain-language explanation
- Informational suggestion
- Safety disclaimer

## AI / RAG Demonstration

A separate AI/RAG workflow demonstrates how relevant knowledge can be retrieved from an AirAware knowledge base and used to generate an understandable explanation.

The demonstrated workflow uses knowledge about:

- AQI categories
- PM2.5 and PM10
- Activity intensity
- Responsible limitations

The current website does **not** contain an automated RAG pipeline. The AI/RAG component is demonstrated separately as a prototype workflow.

## Responsible AI

AirAware AI is designed as an educational decision-support prototype.

The project:

- Avoids unnecessary personal information
- Does not make demographic assumptions
- Explains the informational basis of its outputs
- Does not provide medical diagnosis or personalized medical advice

For personal health decisions, users should refer to official local air-quality guidance and appropriate professional advice.
